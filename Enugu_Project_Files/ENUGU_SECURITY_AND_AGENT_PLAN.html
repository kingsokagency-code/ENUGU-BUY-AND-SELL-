Part 1: The 5-Layer Security Defense

1. Key Isolation & Server-Only Execution

Threat: Secret keys exposed in browser code.

Defense: All secret keys (Paystack, Supabase Service Role, Gemini) are strictly executed inside Next.js Server Actions. They are NEVER exposed to client JavaScript.

2. Supabase Row Level Security (RLS)

Threat: Malicious users tampering with database queries in browser console.

Defense: Every table uses strict RLS policies. Users can ONLY modify records tied to their verified User ID (auth.uid() = user_id).

3. Paystack HMAC SHA512 Webhook Verification

Threat: Hackers spoofing fake "Payment Success" notifications.

Defense: Every transaction notification is verified via cryptographic HMAC SHA512 signature hash matching. Unverified payloads are rejected immediately.

4. Zod Input Sanitization & XSS Defense

Threat: SQL Injection and Cross-Site Scripting (XSS) in store titles/chat.

Defense: Every API endpoint validates payload structure with Zod schemas. Next.js auto-escapes HTML strings.

5. Git Secrets Hardening

Threat: Accidental push of credentials to GitHub.

Defense: Pre-commit secret scanning hooks and automated .gitignore checks.
